Connect Android over Wi‑Fi

On the phone: Developer options → Wireless debugging (Android 11+), same network as this computer. Pair once with the code, then connect with the address on the Wireless debugging screen.

A device is missing?
  • Android phone: Developer options → USB debugging on, then accept Allow USB debugging on the phone. A phone waiting for that shows as unauthorized.
  • iPhone: unlock it, tap Trust This Computer and turn on Settings → Privacy & Security → Developer Mode. Inspecting needs mobilecli's agent once: mobilecli agent install --device <udid> --provisioning-profile <file>.
  • iPhone over Wi‑Fi: connect it by cable once, enable Connect via network in Xcode → Devices and Simulators; then it is listed on the same network.
  • Simulators are listed after their first boot; emulators from the Android SDK's AVDs.
